Client-Side WebGPU AI Architecture & Security

        

        
      

      

        

          

            🔒 Zero Source Code Exposure
          

          

            The AI model has no access to your repository files, backend code (Python, Rust, Node.js), database configurations, or environment variables. It receives only the isolated JSON schema of the active endpoint.
          

        


        

          

            🚫 Zero Direct File Write Access
          

          

            The model runs entirely inside your browser's sandboxed JavaScript runtime via WebGPU / WebAssembly. It has no OS-level filesystem permissions. Model output is parsed and only written to the in-memory editor textarea.
          

        


        

          

            ⚡ 100% Local Inference & Air-Gapped Privacy
          

          

            Powered by SmolLM2-135M-Instruct via ONNX / Transformers.js. Model weights are cached locally in your browser's IndexedDB. Zero prompts, schemas, or tokens leave your workstation.
